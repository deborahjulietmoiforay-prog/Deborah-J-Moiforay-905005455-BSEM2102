## What the program does
`stack_evaluator.py` reads mathematical expressions from `input.txt`, evaluates each one
using a stack-based algorithm, and writes the answers to `output.txt` in the same layout
as the input (one result per block, blocks divided by the same separator line).

## Files
| File | Purpose |
|---|---|
| `stack_evaluator.py` | Python source code (Stack class, evaluator, file handling) |
| `input.txt` | Sample input used for testing |
| `output.txt` | Output generated by the program |
| `README.md` | This document |

## Requirements
Python 3.8 or newer. No external libraries are needed.

## How to run
1. Put `stack_evaluator.py` and `input.txt` in the same folder.
2. Open a terminal in that folder and run: `python stack_evaluator.py`
3. Results are printed on screen and saved in `output.txt`.

To use other file names: `python stack_evaluator.py my_input.txt my_output.txt`

## Input file structure
- One mathematical expression per line.
- Expressions are divided by a line made only of dashes, e.g. `-----`.
- Supported: `+ - * /`, parentheses, decimal numbers, spaces, and negative numbers (e.g. `-5 + 3`).

## Output file structure
Each result replaces its expression, and the same separator line is reused:

    13
    -----
    16
    -----
    -10

Whole numbers are written without a decimal point (13, not 13.0); other results are
rounded to at most 6 decimal places.

## How it works
1. The `Stack` class provides `push`, `pop`, `peek` (plus `is_empty` and `size`).
2. `tokenize()` splits an expression into numbers, operators and brackets.
3. `evaluate_expression()` uses two stacks (values and operators) with the rules that
   `* /` come before `+ -`, and brackets override precedence.
4. `process_file()` reads the input, evaluates each expression and writes the output file.

## Assumptions and limitations
- The separator is any line of three or more dashes; the first one found is reused in the output.
- Blank lines are ignored.
- Exponents (`^`), functions (`sqrt`) and variables are not supported.
- Invalid expressions do not crash the program; the output shows a message instead,
  e.g. `Error: Division by zero`, `Error: Unbalanced parentheses`.
- Note: `(8 / 4) + 7 * 2` equals 16. The sample output in the assignment sheet shows 17,
  which appears to be a typo.
